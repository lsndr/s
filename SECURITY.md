# Security policy

## Supported versions

The packages are versioned independently and are all `0.x`. Only the latest published version of each package (`@lsndr/bus`, `@lsndr/domain`, `@lsndr/logger`) receives security fixes.

## Reporting a vulnerability

Please don't report vulnerabilities in public issues, pull requests or discussions.

Use GitHub's private vulnerability reporting instead: open the [Security tab](https://github.com/lsndr/s/security), choose **Report a vulnerability**, or go straight to the [report form](https://github.com/lsndr/s/security/advisories/new).

Include as much of the following as you can:

- the affected package and version
- a description of the issue and its impact
- steps or a minimal code sample to reproduce it

A fix is published as a new release of the affected package, and the advisory is published after it.
